Instala Vork CLI en Windows, macOS o Linux

Detecta automáticamente tu sistema operativo y directorio de trabajo actual.

powershell (Windows)
PS >
irm https://vork-st1k.onrender.com/cli/install.ps1 | iex
zsh / bash (macOS & Linux)
$ >
curl -fsSL https://vork-st1k.onrender.com/cli/install.sh | bash
cmd.exe (Windows)
C:\>
curl -fsSL https://vork-st1k.onrender.com/cli/install.cmd -o install.cmd && install.cmd && del install.cmd

Ingeniería & Rendimiento

Ventajas y Arquitectura del Motor

Por qué la terminal unificada de Vork transforma flujos manuales en pipelines automatizados de ingeniería multimedia.

ARQUITECTURA MODULAR

Micro-Drivers Desacoplados

Submódulos autónomos para cada disciplina que se cargan dinámicamente en memoria según la orden solicitada por el operador.

INSTALADOR UNIVERSAL

Comando 1-Línea Multiplataforma

Despliegue automático en Windows PowerShell, Linux y macOS sin requerir compiladores locales ni configuraciones manuales.

ORQUESTACIÓN DE AGENTES

Modo Pair Programming

Protocolo especializado para coordinar agentes autónomos y asistentes de código con feedback estructurado y diagnósticos en vivo.

TUBERÍAS UNIX Y PIPES

Automatización en Scripts CI/CD

Soporte completo de flujos estándar stdin / stdout, redirección de archivos y ejecución desatendida en pipelines.

ACTUALIZACIÓN CONTINUA

Comando vork update

Sincronización instantánea con el repositorio central para incorporar los últimos algoritmos y correcciones de ingeniería.

LOGGING ESTRUCTURADO

Salida JSON & Modo Silencioso

Serialización limpia en formato JSON y banderas --quiet para procesar resultados con herramientas de terminal o scripts.
