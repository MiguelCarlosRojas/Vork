Ingeniería & Rendimiento

Ventajas y Arquitectura del Motor

Por qué el separador neuronal Demucs de Vork aísla acapellas e instrumentales con mínima fuga espectral y claridad acústica.

RED NEURONAL DEMUCS

Separación de Fuentes v4

Arquitectura convolucional temporal con modelado espectral para aislar voz humana de bases musicales con máxima nitidez.

CANCELACIÓN DE FASE

Acapella & Karaoke Puros

Supresión de armónicos correlacionados sin artefactos metálicos ni pérdida de graves en la pista instrumental resultante.

CALIDAD MASTERING

Exportación a 44.1 kHz / 16-bit

Generación de pistas separadas en contenedores WAV sin compresión y MP3 a 320 kbps listas para mezcla profesional en DAW.

ESPECTROGRAMA DUAL

Monitoreo Visual en Canvas

Análisis de energía espectral por frecuencias en tiempo real para verificar el aislamiento auditivo de la voz y la pista instrumental.

BALANCE DINÁMICO

Faders de Canal Independiente

Preescucha interactiva de dos canales para calibrar ganancia y verificar el balance acústico antes de descargar los stems.

API DE SEPARACIÓN

Microservicio de Stems REST

Endpoint /api/separator/process para integrar separación de fuentes en cadenas de DJing, karaoke o plataformas de remix.

Guía de Integración

Conecta Vork a tu Aplicación

Separa voz (acapella) y pista instrumental (karaoke) mediante IA de Demucs consumiendo la API REST de Vork.

# Separación de stems mediante cURL
curl -X POST https://vork-st1k.onrender.com/api/separator/process \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=jNQXAC9IVRw",
    "quality": "lossless"
  }'
// separator-service.js (Node.js 18+ / Navegador)
const response = await fetch("https://vork-st1k.onrender.com/api/separator/process", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    url: "https://www.youtube.com/watch?v=jNQXAC9IVRw",
    quality: "lossless"
  })
});

const data = await response.json();
console.log("Pista Vocal:", data.vocalUrl);
console.log("Pista Instrumental:", data.instrumentalUrl);
# separator_service.py (Python Requests)
import requests

payload = {
    "url": "https://www.youtube.com/watch?v=jNQXAC9IVRw",
    "quality": "lossless"
}

res = requests.post("https://vork-st1k.onrender.com/api/separator/process", json=payload)
data = res.json()
print("Voz:", data.get("vocalUrl"))
print("Instrumental:", data.get("instrumentalUrl"))
