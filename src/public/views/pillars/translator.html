Ingeniería & Rendimiento

Ventajas y Arquitectura del Motor

Por qué el motor de Vork supera a los widgets tradicionales de traducción en la web y garantiza máxima velocidad sin saturar la red.

ENVIO CONSOLIDADO

Petición Única por Lotes

Recorre el árbol del DOM con TreeWalker y despacha todos los textos en un solo payload comprimido texts: [...] sin saturar la red.

CACHE DUAL EN RAM

Memoria RAM Cero Retardo

Mantiene una memoria RAM LRU en navegador y servidor para resolver a las consultas previas en 0ms sin cuotas extras de traducción.

REPARTO EN CHUNKS

Segmentación en Paralelo

Segmenta peticiones masivas en chunks de 35 frases con rejectOnPartialFail: false garantizando una total disponibilidad en la red.

COOKIES DE SESION

Persistencia con Cookies

Guarda la preferencia del visitante en la cookie vork_lang para restaurar la traducción antes del renderizado sin destello alguno.

IDIOMAS EN LA RED

Soporte para 200 Idiomas

Brinda amplia compatibilidad con más de +200 idiomas globales mediante una resolución en O(1) insensible a mayúsculas y dialectos.

CONEXION CON APIS

Integración con API REST

Permite enlazar plataformas externas mediante endpoints en arquitectura REST y serialización JSON estándar en toda la red mundial.

// translator.mjs (Node.js 18+ Nativo)
export async function translateText(text, targetLanguage = "en") {
  const response = await fetch("https://vork-st1k.onrender.com/api/translate", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text, targetLanguage })
  });

  const data = await response.json();
  if (!response.ok) throw new Error(data.error || "Translation failed");
  return data.translatedText;
}

// Ejemplo de uso:
const resultado = await translateText("Vork unifica la traducción masiva.", "en");
console.log("Traducción:", resultado);
// server.js (Express.js Proxy / Microservicio)
const express = require("express");
const app = express();
app.use(express.json());

app.post("/api/custom-translate", async (req, res) => {
  const { text, targetLanguage = "en" } = req.body;
  try {
    const apiRes = await fetch("https://vork-st1k.onrender.com/api/translate", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ text, targetLanguage })
    });
    const result = await apiRes.json();
    return res.status(apiRes.status).json(result);
  } catch (error) {
    return res.status(500).json({ success: false, error: error.message });
  }
});

class TranslationController extends Controller

    public function translate(Request $request)
    {
        $validated = $request->validate([

        ]);

        return response()->json($response->json(), $response->status());
    }

// VorkTranslationService.java (Spring Boot 3 / Java 17+)
package com.vork.service;

import org.springframework.stereotype.Service;
import org.springframework.web.client.RestClient;
import java.util.Map;

@Service
public class VorkTranslationService {

    private final RestClient restClient = RestClient.create();

    public String translate(String text, String targetLang) {
        Map<String, String> payload = Map.of(
            "text", text,
            "targetLanguage", targetLang
        );

        Map response = restClient.post()
            .uri("https://vork-st1k.onrender.com/api/translate")
            .header("Content-Type", "application/json")
            .body(payload)
            .retrieve()
            .body(Map.class);

        return (String) response.get("translatedText");
    }
}
# translation_service.py (Python Requests / FastAPI)
import requests

def translate(text: str, target_lang: str = "en") -> str:
    url = "https://vork-st1k.onrender.com/api/translate"
    payload = {
        "text": text,
        "targetLanguage": target_lang
    }
    headers = {"Content-Type": "application/json"}

    response = requests.post(url, json=payload, headers=headers, timeout=10)
    data = response.json()
    return data.get("translatedText", "")
