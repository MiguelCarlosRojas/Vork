0. ¿Cómo Funciona la Integración en los 9 Pilares?

Vork opera bajo una arquitectura modular desacoplada de microservicios. Puedes integrar cada uno de los 9 pilares tecnológicos según las necesidades de tu sistema:

Pilar Tecnológico Mecanismo de Conexión Casos de Uso Ideales Ventajas Clave
Pilar 1: Traductor en la Nube SDK JS (vork.js) o REST POST /api/translate. Traducción web en tiempo real, localización de catálogos y sistemas multilingües. 1 sola consulta HTTP para todo el DOM, persistencia por cookie técnica, 0ms desde memoria RAM.
Pilar 2: Texto a Voz (TTS) REST POST /api/tts y catálogo GET /api/tts/voices. Audiolibros, asistentes virtuales, accesibilidad auditiva y doblaje dinámico. 24 voces humanas neuronales, modulación de velocidad y tono, entrega en buffer WAV / MP3.
Pilar 3: Conversor Multimedia REST POST /api/media/convert e inspección POST /api/media/info. Extracción de audio de videos, conversión a MP3 hasta 320 kbps y video MP4 hasta 1080p. Soporta YouTube, TikTok sin marca, Instagram, Facebook y Twitter; modo lote de hasta 10 URLs.
Pilar 4: Separador de Stems (Demucs v4) REST POST /api/separator/process y streaming /api/separator/stream. Karaoke profesional, remezclas, transcripción vocal y práctica musical. Aislamiento acústico a -48dB sin diafonía entre pista instrumental y voz acapella.
Pilar 5: Procesador de Imágenes REST POST /api/image/convert y catálogo /api/image/formats. Optimización web masiva, transcodificación de catálogos y compresión WebP/AVIF. Filtro LANCZOS de alta resolución, reducción de peso hasta un 80% y exportación en 7 formatos.
Pilar 6: Estudio y Fondo IA REST POST /api/image/remove-bg y soporte FormData multi-part. Fotografía de e-commerce, avatares de perfil y composición gráfica profesional. Segmentación neuronal de siluetas subpíxel y exportación PNG transparente o con fondo de color.
Pilar 7: Generador de Imágenes IA REST POST /api/image/generate (FLUX.1 schnell). Generación artística, diseño conceptual, portadas y prototipado visual. Salida fotorrealista en 1024x1024, sin marcas de agua y relaciones de aspecto personalizadas.
Pilar 8: Vork CLI & Agentes Ejecutable CLI / PowerShell / Terminal desatendida. Pipelines de CI/CD, tareas batch, scripts de terminal y automatización con agentes. Sintaxis directa, comandos unificados con diagonal y salida estructurada JSON / pipe.
Pilar 9: Vork Desktop Asistente nativo para Windows (Always-on-Top). Productividad manos libres, control de ventanas, agenda Google, Spotify y Excel. Huella vocal biométrica exclusiva, respuesta neuronal en español y cero planes de pago.

1. Integración en Frontend con el SDK JavaScript

El SDK para navegadores examina el árbol DOM, recolecta de manera transparente todos los nodos de texto visibles respetando elementos interactivos (botones, enlaces, inputs) y envía las cadenas agrupadas en un solo paquete HTTP para optimizar el consumo de red y no bloquear la interfaz.

Paso 1: Incluir el Script en tu HTML

Añade la etiqueta <script> al final del <body> o dentro de <head>:

HTML / ETIQUETA SCRIPT CDN 
<script src="https://vork-st1k.onrender.com/js/vork.js"></script>

Paso 2: Código de Ejemplo Funcional Completo

Copia y pega este archivo HTML en tu computadora para probar la traducción en tiempo real:

HTML COMPLETO / CLIENTE MÍNIMO 
<!DOCTYPE html>

<head>
  <meta charset="UTF-8">
  <title>Mi Sitio Multilingüe con Vork</title>
</head>

  <header>

[ 02 // BACKEND_NODEJS ]

2. Consumo desde Backend (Node.js & TypeScript)

Invoca la API desde cualquier servidor Node.js, Express, Next.js, Fastify o NestJS mediante el estándar nativo fetch sin requerir librerías externas.

NODE.JS / TRADUCCIÓN POR LOTES (BATCH) 
async function traducirLote(listaTextos, idiomaDestino) {
  const url = "https://vork-st1k.onrender.com/api/translate";
  const respuesta = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      texts: listaTextos,
      targetLanguage: idiomaDestino
    })
  });

  const datos = await respuesta.json();
  if (!datos.success) throw new Error(datos.error || "Error al procesar lote");
  return datos.translatedTexts; // Array ordenado garantizado
}

// Ejemplo:
traducirLote(["Inicio", "Configuración", "Cerrar Sesión"], "en")
  .then(resultado => console.log(resultado));
  // Salida: ["Home", "Settings", "Log Out"]

3. Consumo desde Python

Integración directa para scripts de ciencia de datos, FastAPI o pipelines de Machine Learning:

PYTHON / MÓDULO REQUESTS (TEXTO Y BATCH) 
import requests

API_URL = "https://vork-st1k.onrender.com/api/translate"

def traducir(contenido, idioma_destino):
    headers = {"Content-Type": "application/json"}
    payload = {"texts": contenido, "targetLanguage": idioma_destino} if isinstance(contenido, list) else {"text": contenido, "targetLanguage": idioma_destino}
    response = requests.post(API_URL, json=payload, headers=headers, timeout=60)
    response.raise_for_status()
    data = response.json()
    return data.get("translatedTexts") if isinstance(contenido, list) else data.get("translatedText")

print(traducir("Servicio de traducción en la nube", "en"))
# Salida: "Cloud translation service"

4. Integración del Pilar 2: Texto a Voz (TTS)

Genera locución humana en tiempo real con 24 voces neuronales desde JavaScript o cualquier backend:

JAVASCRIPT / SÍNTESIS Y REPRODUCCIÓN DE AUDIO 
async function reproducirTexto(texto, voz = "es-ES-AlvaroNeural") {
  const res = await fetch("https://vork-st1k.onrender.com/api/tts", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      text: texto,
      voice: voz,
      rate: 1.0,
      pitch: 1.0
    })
  });
  
  const blob = await res.blob();
  const audioUrl = URL.createObjectURL(blob);
  const audio = new Audio(audioUrl);
  audio.play();
}

// Consultar catálogo de voces disponibles
fetch("https://vork-st1k.onrender.com/api/tts/voices")
  .then(r => r.json())
  .then(data => console.log("Voces disponibles:", data.voices));

8. Códigos de Respuesta y Diagnóstico de Errores

El gateway de Vork emite códigos de estado HTTP estándar acompañados de un mensaje aclaratorio en JSON para todos los servicios:

Código HTTP Estado Causa Frecuente Acción Recomendada
200 OK Exitoso Petición procesada correctamente. Consumir datos de respuesta (translatedText, buffer binario o downloadUrl).
400 Bad Request Error de Validación Faltan parámetros requeridos (ej. texto vacío, muestra ausente o URL no soportada). Revisar el formato JSON / FormData y encabezados correspondientes.
500 Internal Error Fallo del Motor Problema temporal de procesamiento en el microservicio. Implementar reintento exponencial tras 2 a 3 segundos.
503 Unavailable Instancia Despertando La máquina en Render está saliendo del modo reposo (cold start). Esperar de 25 a 35 segundos y reintentar la solicitud.
