SESIÓN 01

Arquitectura Global y Filosofía de Diseño

Principios fundamentales de Vork v2.5.0 como microservicio unificado de alto rendimiento.

1.1 El Principio de 1 Sola Consulta Consolidada

Los traductores tradicionales envían cientos de peticiones HTTP individuales (una por cada párrafo o etiqueta <span>), colapsando el pool de conexiones del navegador, activando límites de tasa (rate limiting) y provocando bloqueos de interfaz o saltos visuales desagradables (layout shift).

Vork implementa el Algoritmo de Consolidación Atómica: el SDK frontend escanea la totalidad del DOM en una sola pasada sincrónica, recopila todos los segmentos de texto en un array ordenado, y despacha una única petición HTTP POST al microservicio. El servidor traduce el lote en paralelo y devuelve el array simétrico, reinyectándose en el DOM en un único ciclo de renderizado.

Pilar 7: Vork CLI (Entorno Centrado en la Terminal)

Orquestación de agentes autónomos, concurrencia de subagentes y comandos con diagonal en tu base de código.

8.1 Arquitectura del CLI y Modelo de Agentes

Vork CLI es un entorno ligero enfocado en la terminal para interactuar con agentes de inteligencia artificial directamente sobre tus archivos de código. Describe lo que necesitas en lenguaje natural y los agentes ejecutan, depuran y coordinan herramientas manteniendo la trazabilidad completa.

Control Concurrente con Subagentes: Permite delegar tareas pesadas en segundo plano a sesiones paralelas. Escribe /agents para abrir el panel de control y pulsa ctrl+k para autorizar comandos de terminal de forma instantánea.

8.2 Métodos Oficiales de Instalación en Windows

Puedes instalar y activar Vork CLI ejecutando una sola instrucción:

powershell (automatizado)
PS >
irm https://vork-st1k.onrender.com/cli/install.ps1 | iex
cmd.exe (símbolo del sistema)
C:\>
curl -fsSL https://vork-st1k.onrender.com/cli/install.cmd -o install.cmd && install.cmd && del install.cmd
SESIÓN 09

Pilar 8: Conversor y Procesador de Imágenes Universal

Motor de transcodificación, optimización y redimensionamiento LANCZOS multiformato con soporte de canal alfa.

9.1 Motor de Procesamiento Pillow y Resampling LANCZOS

El subsistema de imagen de Vork opera mediante un worker nativo en Python optimizado con la biblioteca Pillow (PIL). Procesa imágenes de hasta 50 MB con corrección automática de orientación basada en metadatos EXIF (ImageOps.exif_transpose) y filtrado antialiasing de 8 coeficientes Image.Resampling.LANCZOS.

Formato Canal Alfa (RGBA) Compresión y Optimización Casos de Uso Recomendados
PNG Sí (Transparencia Completa) Compresión DEFLATE sin pérdida Iconos, logotipos, gráficos con fondos transparentes y capturas
JPEG / JPG No (Composición sobre fondo blanco) Cuantización DCT ajustable (1 - 100) Fotografías de alta compresión y miniaturas de catálogo
WEBP Sí (Con o sin pérdida) Compresión Google VP8X (method=6) Publicación web moderna de máximo rendimiento y menor peso
GIF Sí (Paleta indexada de 256 colores) Adaptativa con dithering Animaciones cortas e imágenes gráficas simples
ICO Sí (Multirresolución) 16x16, 32x32, 48x48, 64x64, 128x128, 256x256 Favicons para navegadores web y ejecutables Windows
BMP / TIFF Sí (TIFF Deflate) Sin compresión / TIFF Deflate Impresión profesional y preservación fotográfica cruda

9.2 Algoritmo de Conversión y Redimensionamiento Proporcional

El motor calcula automáticamente las proporciones originales si solo se especifica ancho (width) o alto (height), evitando deformaciones visuales:

// PYTHON - ALGORITMO DE ESCALADO Y GESTIÓN DE CANALES 
# Si se solicita redimensionamiento proporcional manteniendo la relación de aspecto
if width and not height:
    new_w = int(width)
    new_h = int((new_w / orig_w) * orig_h)
    img = img.resize((new_w, new_h), Image.Resampling.LANCZOS)
elif height and not width:
    new_h = int(height)
    new_w = int((new_h / orig_h) * orig_w)
    img = img.resize((new_w, new_h), Image.Resampling.LANCZOS)
SESIÓN 10

Pilar 9: Estudio y Eliminador de Fondo IA (rembg U2-Net)

Aislamiento biométrico y de objetos con redes neuronales profundas U2-Net, generación de máscaras alfa y sustitución compositiva.

10.1 Red Neuronal Profunda U2-Net y Detección de Saliencia

A diferencia de los métodos heurísticos basados en color (Chroma Keying simple) que degradan los bordes de cabellos o prendas, el Pilar 9 utiliza la arquitectura de red neuronal profunda U2-Net de dos niveles a través del motor rembg. La red genera una máscara de probabilidad continua entre 0.0 y 1.0 (canal alfa flotante) logrando transiciones suaves sin bordes dentados.

Procesamiento Local Libre de Costos: Inferencia ejecutada directamente en el cluster backend sin cuotas de proveedores externos ni marcas de agua impuestas.

10.2 Modos de Modificación y Composición de Fondo

Vork ofrece 4 modos de modificación de fondo:

  • transparent: Genera un archivo PNG RGBA con el fondo completamente transparente. Ideal para diseño gráfico y catálogos.
  • color: Reemplaza el fondo por un color sólido arbitrario especificado en código HEX (ejemplo: #FFFFFF o #00F0FF).
  • custom_bg: Compone el sujeto recortado sobre cualquier imagen de fondo provista por el usuario, ajustando la escala con ImageOps.fit.
  • prompt: Genera un fondo completamente nuevo a partir de una descripción en lenguaje natural mediante el cluster de difusión generativa Pollinations.

Guía de Integración Frontend SDK

Inicialización en Vanilla JS, frameworks SPA reactivos y aplicaciones server-side.

8.1 Integración en Vanilla JavaScript

Descarga o importa el script cliente vork.js e inicializa la clase:

// HTML & JAVASCRIPT VANILLA 
<script src="https://vork-st1k.onrender.com/js/vork.js"></script>
<script>
  // Inicialización del cliente con persistencia en Cookies
  const translator = new Vork({
    endpoint: "https://vork-st1k.onrender.com/api/translate",
    useCookies: true,
    batchSize: 500,
    ignoreSelectors: [".no-translate", "[data-no-translate]"]
  });

  // Traducir a Francés
  translator.translatePage("fr");

  // Restaurar idioma original
  // translator.restoreOriginal();
</script>
Propiedad de Configuración Tipo de Dato Valor por Defecto Descripción del Comportamiento
endpoint string (URL) "/api/translate" Ruta absoluta o remota del microservicio de traducción por lotes
useCookies boolean true Persiste automáticamente la preferencia de idioma en la cookie técnica vork_lang
batchSize number 500 Límite máximo de nodos de texto empaquetados por cada consulta atómica
ignoreSelectors Array<string> [".no-translate"] Lista de selectores CSS y atributos que serán excluidos del recorrido recursivo

8.2 Integración en React / Next.js / Vue

En aplicaciones React o Vue, inicializa la instancia dentro de un hook de ciclo de vida (useEffect o onMounted) para garantizar que el DOM cliente esté disponible:

// REACT / NEXT.JS INTEGRATION COMPONENT 
import { useEffect } from 'react';

export default function Layout({ children }) {
  useEffect(() => {
    if (window.Vork) {
      window.ctInstance = new window.Vork({
        endpoint: "https://vork-st1k.onrender.com/api/translate",
        useCookies: true,
        batchSize: 500
      });
    }
  }, []);

  return <div>{children}</div>;
}
