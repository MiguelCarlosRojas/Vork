[ 00 // ARCHITECTURE_OVERVIEW ]

0. ¿Cómo Funciona la Integración en los 9 Pilares?

Vork opera bajo una arquitectura modular desacoplada de microservicios. Puedes integrar cada uno de los 9 pilares tecnológicos según las necesidades de tu sistema:

Pilar Tecnológico Mecanismo de Conexión Casos de Uso Ideales Ventajas Clave
Pilar 1: Traductor en la Nube SDK JS (vork.js) o REST POST /api/translate. Traducción web en tiempo real, localización de catálogos y sistemas multilingües. 1 sola consulta HTTP para todo el DOM, persistencia por cookie técnica, 0ms desde memoria RAM.
Pilar 2: Texto a Voz (TTS) REST POST /api/tts y catálogo GET /api/tts/voices. Audiolibros, asistentes virtuales, accesibilidad auditiva y doblaje dinámico. 24 voces humanas neuronales, modulación de velocidad y tono, entrega en buffer WAV / MP3.
Pilar 3: Clonación de Voz (IA) REST POST /api/voice-clone (multipart/form-data o Base64). Locución personalizada con timbre propio, podcasts sintéticos y agentes de voz corporativos. Extracción bio-acústica de formantes (F0), síntesis de alta fidelidad PCM 16-bit descargable.
Pilar 4: Conversor Multimedia REST POST /api/media/convert e inspección POST /api/media/info. Extracción de audio de videos, conversión a MP3 hasta 320 kbps y video MP4 hasta 1080p. Soporta YouTube, TikTok sin marca, Instagram, Facebook y Twitter; modo lote de hasta 10 URLs.
[ 01 // FRONTEND_INTEGRATION ]

1. Integración en Frontend con el SDK JavaScript

El SDK para navegadores examina el árbol DOM, recolecta de manera transparente todos los nodos de texto visibles respetando elementos interactivos (botones, enlaces, inputs) y envía las cadenas agrupadas en un solo paquete HTTP para optimizar el consumo de red y no bloquear la interfaz.

Paso 1: Incluir el Script en tu HTML

Añade la etiqueta <script> al final del <body> o dentro de <head>:

HTML / ETIQUETA SCRIPT CDN 
<script src="https://vork-st1k.onrender.com/js/vork.js"></script>

Paso 2: Opciones de Inicialización

Al instanciar new Vork(options), dispones de los siguientes parámetros configurables:

Parámetro Tipo Valor por Defecto Descripción
endpoint string "/api/translate" URL absoluta o relativa del servicio de traducción. En producción usa: https://vork-st1k.onrender.com/api/translate.
useCookies boolean true Si es true, guarda el idioma seleccionado en la cookie del navegador para mantener la preferencia en futuras visitas.
batchSize number 500 Número máximo de nodos de texto enviados por petición HTTP.
onStart function null Callback invocado al iniciar la traducción (ideal para mostrar spinners o barras de carga).
onComplete function null Callback invocado cuando todos los textos del DOM han sido reemplazados exitosamente.
onError function null Callback que recibe el error en caso de fallo de red o tiempo de espera agotado.

[ 02 // BACKEND_NODEJS ]

2. Consumo desde Backend (Node.js & TypeScript)

Invoca la API desde cualquier servidor Node.js, Express, Next.js, Fastify o NestJS mediante el estándar nativo fetch sin requerir librerías externas.

2.1 Traducción de Texto Individual

NODE.JS / TEXTO SIMPLE (FETCH) 
async function traducirTexto(texto, idiomaDestino) {
  const url = "https://vork-st1k.onrender.com/api/translate";
  const respuesta = await fetch(url, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      text: texto,
      targetLanguage: idiomaDestino
    })
  });

  if (!respuesta.ok) {
    const errorJson = await respuesta.json().catch(() => ({}));
    throw new Error(errorJson.error || `HTTP Error ${respuesta.status}`);
  }

  const datos = await respuesta.json();
  return datos.translatedText; // Cadena traducida
}

// Ejemplo de uso:
traducirTexto("Servicio de traducción en tiempo real", "en")
  .then(res => console.log("Resultado:", res)) // "Real-time translation service"
  .catch(err => console.error("Error:", err.message));

2.2 Traducción de Lotes Masivos (Micro-batch)

Para catálogos, menús o notificaciones compuestas, envía el arreglo texts para procesar hasta 1,000 cadenas en una sola llamada:

NODE.JS / TRADUCCIÓN POR LOTES (BATCH) 
async function traducirLote(listaTextos, idiomaDestino) {
  const url = "https://vork-st1k.onrender.com/api/translate";
  const respuesta = await fetch(url, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      texts: listaTextos,
      targetLanguage: idiomaDestino
    })
  });

  const datos = await respuesta.json();
  if (!datos.success) {
    throw new Error(datos.error || "Error al procesar lote");
  }

  return datos.translatedTexts; // Array con orden garantizado
}

// Ejemplo:
traducirLote(["Inicio", "Configuración", "Cerrar Sesión"], "en")
  .then(resultado => console.log(resultado));
  // Salida: ["Home", "Settings", "Log Out"]

2.3 Manejo Resiliente del "Cold Start" en Render

En la infraestructura gratuita de Render, la máquina entra en suspensión tras 15 minutos de inactividad. El primer contacto tardará entre 30 y 45 segundos mientras el servidor inicia. Implementa un reintento con retardo (backoff):

NODE.JS / CLIENTE RESILIENTE CON RETRY 
async function traducirConReintento(texto, idioma, maxIntentos = 3) {
  const url = "https://vork-st1k.onrender.com/api/translate";

  for (let intento = 1; intento <= maxIntentos; intento++) {
    try {
      const res = await fetch(url, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ text: texto, targetLanguage: idioma }),
        signal: AbortSignal.timeout(50000) // 50s de margen para Cold Start
      });

      if (res.ok) {
        const data = await res.json();
        return data.translatedText;
      }
    } catch (err) {
      console.warn(`Intento ${intento} fallido. Esperando reactivación...`);
      if (intento === maxIntentos) throw err;
      await new Promise(r => setTimeout(r, 4000 * intento));
    }
  }
}

3. Consumo desde Python

Integración directa para scripts de datos o APIs construidas con FastAPI, Flask, Django o scripts de procesamiento batch:

PYTHON / MÓDULO REQUESTS (TEXTO Y BATCH) 
import requests
from typing import List, Union

API_URL = "https://vork-st1k.onrender.com/api/translate"

def traducir(contenido: Union[str, List[str]], idioma_destino: str) -> Union[str, List[str]]:
    headers = {"Content-Type": "application/json"}
    
    # Detección automática: texto individual o lote
    if isinstance(contenido, list):
        payload = {"texts": contenido, "targetLanguage": idioma_destino}
    else:
        payload = {"text": contenido, "targetLanguage": idioma_destino}
    
    # Timeout amplio para absorber posibles cold starts
    response = requests.post(API_URL, json=payload, headers=headers, timeout=60)
    response.raise_for_status()
    data = response.json()
    
    if isinstance(contenido, list):
        return data.get("translatedTexts", [])
    return data.get("translatedText", "")

# Pruebas de ejecución:
print(traducir("Servicio de traducción en la nube", "en"))
# Salida: "Cloud translation service"

print(traducir(["Facturación", "Inventario", "Reportes"], "fr"))
# Salida: ["Facturation", "Inventaire", "Rapports"]

5. Integración del Pilar 2: Texto a Voz (TTS)

async function reproducirTexto(texto, voz = "es-ES-AlvaroNeural") {
  const res = await fetch("https://vork-st1k.onrender.com/api/tts", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      text: texto,
      voice: voz,
      rate: 1.0,
      pitch: 1.0
    })
  });
  
  const blob = await res.blob();
  const audioUrl = URL.createObjectURL(blob);
  const audio = new Audio(audioUrl);
  audio.play();
}

// 2. Consultar catálogo de 24 voces disponibles
fetch("https://vork-st1k.onrender.com/api/tts/voices")
  .then(r => r.json())

[ 06 // VOICE_CLONE_INTEGRATION ]

6. Integración del Pilar 3: Clonación de Voz con IA

Envía una muestra vocal (grabada o archivo) junto al texto a narrar para obtener una réplica tímbrica en PCM 16-bit:

NODE.JS (FORMDATA / AXIOS) / CLONACIÓN VOCAL 
const axios = require("axios");
const FormData = require("form-data");
const fs = require("fs");

async function clonarVoz(rutaAudioMuestra, guionTexto) {
  const form = new FormData();
  form.append("sample", fs.createReadStream(rutaAudioMuestra));
  form.append("text", guionTexto);
  form.append("stability", "0.75");

  const res = await axios.post("https://vork-st1k.onrender.com/api/voice-clone", form, {
    headers: form.getHeaders(),
    responseType: "arraybuffer"
  });

  fs.writeFileSync("audio_clonado.wav", res.data);
  console.log("Audio sintetizado con tu voz guardado en audio_clonado.wav");
}

8. Códigos de Respuesta y Diagnóstico de Errores

El gateway de Vork emite códigos de estado HTTP estándar acompañados de un mensaje aclaratorio en JSON para todos los servicios:

Código HTTP Estado Causa Frecuente Acción Recomendada
200 OK Exitoso Petición procesada correctamente. Consumir datos de respuesta (translatedText, buffer binario o downloadUrl).
400 Bad Request Error de Validación Faltan parámetros requeridos (ej. texto vacío, muestra ausente o URL no soportada). Revisar el formato JSON / FormData y encabezados correspondientes.
500 Internal Error Fallo del Motor Problema temporal de procesamiento en el microservicio. Implementar reintento exponencial tras 2 a 3 segundos.
503 Unavailable Instancia Despertando La máquina en Render está saliendo del modo reposo (cold start). Esperar de 25 a 35 segundos y reintentar la solicitud.
