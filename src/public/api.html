SESIÓN 01

Gateway & Protocolo

Base URL de producción, requisitos de cifrado HTTPS con TLS 1.3, encabezados obligatorios y estructura unificada de errores.

[ 1.1 // BASE_URL ]

URL Base del Servidor

Todas las rutas son relativas a la dirección canónica en producción:

Base URL de Producción 
https://vork-st1k.onrender.com/api

Se requiere comunicación estricta mediante HTTPS con TLS 1.3. Las solicitudes HTTP no cifradas se redirigen automáticamente a HTTPS.

[ 1.2 // HEADERS ]

Encabezados HTTP Requeridos

Encabezado Valor Requerido Detalle
Content-Type application/json Obligatorio (POST) Define que el cuerpo de la solicitud viaja en JSON estricto.
Accept application/json Opcional Garantiza que la respuesta se devuelva estructurada en JSON.
Access-Control-Allow-Origin * Automático Habilitado en todos los endpoints para clientes web frontend.
[ 1.3 // ERROR_SCHEMA ]

Esquema Estándar de Respuestas de Error

Cuando una solicitud falla por validación de parámetros (HTTP 400) o error interno (HTTP 500), el servidor responde con el siguiente formato JSON:

Esquema de Error JSON (HTTP 400 / 500) 
{
  "success": false,
  "error": "El idioma objetivo es requerido"
}
SESIÓN 02

Pilar 1: API de Traducción DOM

Endpoints para traducción atómica de lotes, detección de idiomas, comprobación de latencia y diagnóstico.

[ ENDPOINT T.01 ] POST

POST /api/translate — Traducción de Lotes & Texto Simple

Endpoint principal para traducción de cadenas de texto y micro-lotes en una sola solicitud HTTP.

POST /api/translate Payload: texto individual

2.1 Traducción de Texto Simple

Cuerpo de la Petición (Request Body)

Propiedad Tipo Restricción Descripción
text string 1 a 5,000 caracteres Texto en lenguaje natural a traducir.
targetLanguage string Código ISO (ej. "en") Idioma de destino requerido.

Ejemplo de Solicitud (cURL)

Comando cURL (POST Texto Simple) 
curl -X POST "https://vork-st1k.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Infraestructura de microservicios en la nube",
    "targetLanguage": "en"
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "translatedText": "Cloud microservices infrastructure"
}
POST /api/translate Payload: arreglo de textos

2.2 Traducción por Micro-lotes (Batch)

Permite enviar hasta 1,000 cadenas de texto en una sola conexión HTTP. Garantiza el orden idéntico de los elementos de entrada en la respuesta.

Cuerpo de la Petición (Request Body)

Propiedad Tipo Restricción Descripción
texts Array<string> 1 a 1,000 elementos Lista de cadenas a traducir de forma simultánea.
targetLanguage string Código ISO (ej. "en") Idioma de destino requerido.

Ejemplo de Solicitud (cURL)

Comando cURL (POST Lote de Textos) 
curl -X POST "https://vork-st1k.onrender.com/api/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "texts": ["Configuración", "Seguridad", "Facturación"],
    "targetLanguage": "en"
  }'

Respuesta Exitosa (HTTP 200 OK)

Respuesta JSON (HTTP 200 OK) 
{
  "translatedTexts": [
    "Settings",
    "Security",
    "Billing"
  ]
}

GET /api/tts/stream — Streaming de Audio HTTP 206 Chunks

Parámetros de Consulta (Query String)

Parámetro Tipo Obligatorio Valor por Defecto Descripción Técnica

pitch number No 1.0 Tono acústico base (rango admitido: 0.5 a 1.5).

Pilar 6: Vork DJ Mezclador

Arquitectura cliente en Web Audio API, curvas de ganancia de crossfader y filtros paramétricos de 3 bandas.

[ ENDPOINT D.01 ] DSP / AUDIO GRAPH

Motor Web Audio & Ingesta para Vork DJ

Especificación de ruteo y preparación de pistas para la consola de mezcla dual y cola secuencial.

Las pistas del Vork DJ se preparan utilizando POST /api/media/convert con formato MP3 y 320 kbps. El reproductor utiliza streaming HTTP 206 y nodos Web Audio API con ecualización de 3 bandas paramétricas (Low, Mid, High), control de crossfader de energía constante y scratch en tiempo real.

Petición cURL para precargar pista en consola DJ

Pilar 8: API de Conversor y Procesador de Imágenes

Transcodificación multiformato (PNG, JPG, WEBP, GIF, BMP, TIFF, ICO), redimensionamiento LANCZOS y compresión sin pérdidas.

GET /api/image/formats

Retorna el catálogo oficial de formatos de imagen admitidos, capacidades de canal alfa, modos de estudio y límites de tamaño por archivo.

// CURL - FORMATOS SOPORTADOS 
curl -X GET https://vork-st1k.onrender.com/api/image/formats   -H "Accept: application/json"
POST /api/image/convert

Convierte una imagen (subida en Base64 o URL remota validada contra SSRF) al formato especificado, aplicando redimensionamiento LANCZOS opcional y cuantización de calidad.

Campo del Body Tipo Obligatorio Descripción
imageBase64 string Condicional Imagen cruda codificada en Base64 (con o sin prefijo data:image/*). Límite 50 MB.
url string Condicional URL remota directa de la imagen a convertir (blindada con SSRF Guard).
targetFormat string Opcional Formato destino: png, jpg, webp, gif, bmp, tiff, ico. (Por defecto: png).
quality number Opcional Calidad de salida para JPG y WEBP (1 - 100). Por defecto: 90.
width / height number Opcional Dimensiones en píxeles. Si solo se especifica uno, el otro se calcula automáticamente manteniendo el aspecto.
// EJEMPLO DE PETICIÓN CURL 
curl -X POST https://vork-st1k.onrender.com/api/image/convert   -H "Content-Type: application/json"   -d '{
    "url": "https://vork-st1k.onrender.com/img/logo.png",
    "targetFormat": "webp",
    "quality": 85,
    "width": 512
  }'
// RESPUESTA JSON DE ÉXITO (200 OK) 
{
  "status": "success",
  "id": "img_6f4b2a8d1e0c",
  "filename": "imagen_convertida_6f4b2a.webp",
  "format": "webp",
  "width": 512,
  "height": 512,
  "origWidth": 1024,
  "origHeight": 1024,
  "sizeBytes": 28410,
  "sizeFormatted": "27.74 KB",
  "streamUrl": "/api/image/stream?id=img_6f4b2a8d1e0c",
  "downloadUrl": "/api/image/download?id=img_6f4b2a8d1e0c"
}
GET /api/image/stream?id={id}

Transmite la imagen procesada en flujo binario con la cabecera Content-Type correspondiente al formato (ej. image/webp) para renderizado instantáneo en etiquetas <img>.

GET /api/image/download?id={id}

Descarga forzada del archivo de imagen convertido con cabecera segura Content-Disposition: attachment; filename="..." libre de inyección CRLF.

Pilar 9: API de Estudio y Eliminador de Fondo IA

Segmentación biométrica y de objetos mediante redes neuronales profundas U2-Net con rembg sin límites de uso.

POST /api/image/remove-background

Aísla el sujeto principal de una imagen eliminando el fondo de forma precisa. Permite exportar en PNG transparente, sustituir el fondo por un color sólido HEX o componerlo creativamente sobre otra imagen de fondo.

Campo del Body Tipo Obligatorio Descripción
imageBase64 string Condicional Imagen de origen codificada en Base64.
url string Condicional URL remota directa hacia la imagen original.
mode string Opcional Modo de salida: transparent (default), color, custom_bg o prompt.
color string Opcional Color de sustitución en formato HEX (ej: #FFFFFF, #10B981) si el modo es color.
bgImageBase64 string Opcional Imagen de fondo personalizada si el modo es custom_bg.
prompt string Opcional Descripción en lenguaje natural para generar un fondo con IA generativa si el modo es prompt.
// CURL - ELIMINACIÓN DE FONDO TRANSPARENTE 
curl -X POST https://vork-st1k.onrender.com/api/image/remove-background   -H "Content-Type: application/json"   -d '{
    "url": "https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=800",
    "mode": "transparent"
  }'
// CURL - REEMPLAZO POR FONDO DE COLOR HEX (#00F0FF) 
curl -X POST https://vork-st1k.onrender.com/api/image/remove-background   -H "Content-Type: application/json"   -d '{
    "url": "https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=800",
    "mode": "color",
    "color": "#00F0FF"
  }'
// RESPUESTA JSON DE ÉXITO (200 OK) 
{
  "status": "success",
  "id": "bg_a9c8b7e6f5d4",
  "filename": "fondo_ia_transparent_a9c8b7.png",
  "mode": "transparent",
  "format": "png",
  "width": 800,
  "height": 1000,
  "sizeBytes": 425120,
  "sizeFormatted": "415.16 KB",
  "streamUrl": "/api/image/stream?id=bg_a9c8b7e6f5d4",
  "downloadUrl": "/api/image/download?id=bg_a9c8b7e6f5d4"
}
