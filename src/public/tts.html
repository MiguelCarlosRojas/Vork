Ingeniería & Rendimiento

Ventajas y Arquitectura del Motor

Por qué la síntesis neuronal de Vork ofrece entonación humana natural, respuesta en tiempo real y descarga física en alta resolución.

SÍNTESIS MULTILINGÜE

24 Voces Humanas Calibradas

Modelos vocales entrenados con prosodia y dinámica expresiva natural en más de 20 idiomas con timbre nativo y sin resonancias sintéticas.

MODULACIÓN FINA

Control de Pitch y Cadencia

Modulación paramétrica de velocidad de locución (0.5x - 2.0x) y micro-afinación en Hz sin distorsión armónica ni aliasing digital.

STREAMING EN RAM

Buffer Acústico Cero Espera

Pre-renderizado en búfer de memoria con despacho por fragmentos para reproducción inmediata en 0ms sin micro-cortes auditivos.

EXPORTACIÓN DUAL

Descarga Física WAV & MP3

Serialización directa a contenedores WAV PCM sin pérdida y MP3 a 192 kbps listos para producción de podcast y locución.

WEB AUDIO PIPELINE

Decodificación Nativa

Conexión directa al nodo AudioContext del navegador para reproducción balanceada por hardware con ecualización dinámica.

INTEGRACIÓN REST

API REST de Síntesis

Microservicio de alta concurrencia con endpoint /api/tts para invocar locuciones desde Node.js, Python o scripts de frontend.

Guía de Integración

Conecta Vork a tu Aplicación

Integra síntesis vocal neuronal humana directamente en tus microservicios o frontend consumiendo la API REST de Vork.

# Síntesis de voz directa mediante cURL
curl -X POST https://vork-st1k.onrender.com/api/tts \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hola, este es un mensaje sintetizado con Vork",
    "lang": "es",
    "rate": 1.0,
    "pitch": 1.0
  }'
// tts-service.js (Node.js 18+ / Navegador)
const response = await fetch("https://vork-st1k.onrender.com/api/tts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "Hola, este es un mensaje sintetizado con Vork",
    lang: "es",
    rate: 1.0,
    pitch: 1.0
  })
});

const data = await response.json();
console.log("URL de Audio:", data.audioUrl);
# tts_service.py (Python Requests)
import requests

payload = {
    "text": "Hola, este es un mensaje sintetizado con Vork",
    "lang": "es",
    "rate": 1.0,
    "pitch": 1.0
}

res = requests.post("https://vork-st1k.onrender.com/api/tts", json=payload)
data = res.json()
print("Audio generado:", data.get("audioUrl"))
