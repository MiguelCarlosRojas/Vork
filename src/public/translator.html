Ventajas y Arquitectura del Motor

Por qué Vork supera a los widgets tradicionales de traducción en la web.

[ 01 // BATCH_CONSOLIDATION ]

Una Sola Petición Consolidada

Escanea el árbol del DOM mediante TreeWalker y envía todos los textos en un solo payload comprimido texts: [...], eliminando cientos de llamadas de red fragmentadas.

[ 02 // COOKIE_CACHE ]

Persistencia por Cookies

Almacena la preferencia del visitante en la cookie vork_lang. Al recargar o navegar entre enlaces del sitio, el idioma se restaura inmediatamente en 0ms.

[ 03 // RAM_LRU ]

Caché en Servidor de 10,000 Entradas

El backend mantiene una caché LRU de alto rendimiento en memoria RAM. Frases previamente traducidas responden en 0 milisegundos sin consumir cuota de Google Translate.

[ CODE_SNIPPET // INTEGRATION ]

Integración en tu Sitio Web en 2 Pasos

Pega este código en tu archivo HTML para habilitar traducción automática profesional:

HTML & JavaScript Client SDK 
<!-- 1. Cargar el SDK cliente oficial -->
<script src="https://vork-st1k.onrender.com/js/vork.js"></script>
<script>
  document.addEventListener("DOMContentLoaded", () => {
    // Inicializar traductor conectado al microservicio
    window.translator = new Vork({
      endpoint: "https://vork-st1k.onrender.com/api/translate",
      useCookies: true // Persiste el idioma entre páginas y recargas
    });

    // Controladores
    document.getElementById("btn-english").onclick = () => window.translator.translateToEnglish();
    document.getElementById("btn-restore").onclick = () => window.translator.restoreOriginal();
    document.getElementById("select-lang").onchange = (e) => window.translator.translatePage(e.target.value);
  });
</script>
