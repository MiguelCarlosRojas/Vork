[ 02 // REPORTE_DE_INCIDENCIAS ]

Protocolo para Reporte de Fallos

Para agilizar la resolución de incidencias en producción, incluye la siguiente información al enviar un reporte técnico:

  • Timestamp: Fecha y hora exacta de la solicitud (formato ISO 8601 o UTC).
  • Endpoint consultado: Por ejemplo POST /api/translate, POST /api/tts, POST /api/voice-clone o POST /api/media/convert.
  • Payload enviado: Cuerpo JSON o datos de la petición (omitiendo información confidencial).
  • Código HTTP y mensaje de error: Respuesta devuelta por el servidor (ej. 400 Bad Request, 500 Internal Error).
  • Entorno de ejecución: Node.js, navegador (Chrome/Firefox/Safari), Python o cURL.
